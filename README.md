# 🌍 College List Finder

This is a simple web application that lets users search for colleges/universities based on a country name.

## 🚀 Features

- Search for colleges by entering a country name
- Autocomplete country suggestions.
- Clickable college names that open a Google search
- Responsive and modern UI with smooth hover effects

## 🔧 Technologies Used

- HTML5, CSS3, JavaScript
- Axios (for API calls)
- Google Fonts
- Public APIs:
  - Universities API: `http://universities.hipolabs.com/`
  - Countries API: `https://restcountries.com/v2/all`
